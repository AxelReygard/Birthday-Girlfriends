# 🎵 Cara Memasukkan Lagu Justin Bieber - Favorite Girl

## Instruksi:
1. Siapkan file MP3 lagu "Favorite Girl" oleh Justin Bieber
2. Rename file tersebut menjadi: **favorite_girl.mp3**
3. Copy file ke folder ini: `public/assets/music/favorite_girl.mp3`

## Catatan:
- Web sudah dikonfigurasi untuk memutar file dari path: `/assets/music/favorite_girl.mp3`
- Format yang didukung: MP3, OGG, WAV
- Jika file tidak ditemukan, player tetap tampil namun tidak bisa diputar
